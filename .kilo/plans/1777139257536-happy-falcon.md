## 2. Post Model

**File:** `app/Models/Post.php`

```php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\SoftDeletes;
use Spatie\Activitylog\Models\Concerns\LogsActivity;
use Spatie\Activitylog\Support\LogOptions;

class Post extends Model
{
    use SoftDeletes, LogsActivity;

    protected $fillable = [
        'title',
        'slug',
        'excerpt',
        'content',
        'featured_image',
        'author_id',
        'status',
        'published_at',
    ];

    protected $casts = [
        'published_at' => 'datetime',
    ];

    // Relationships
    public function author()
    {
        return $this->belongsTo(User::class, 'author_id');
    }

    // Scopes
    public function scopePublished($query)
    {
        return $query->where('status', 'published')
                     ->whereNotNull('published_at')
                     ->where('published_at', '<=', now());
    }

    public function scopeDraft($query)
    {
        return $query->where('status', 'draft');
    }

    public function scopeArchived($query)
    {
        return $query->where('status', 'archived');
    }

    // Auto-generate slug on save
    public static function booted()
    {
        static::saving(function ($post) {
            if (empty($post->slug)) {
                $post->slug = \Str::slug($post->title);
                // Ensure uniqueness
                $originalSlug = $post->slug;
                $counter = 1;
                while (static::where('slug', $post->slug)->where('id', '!=', $post->id)->exists()) {
                    $post->slug = $originalSlug . '-' . $counter++;
                }
            }
        });

        // Auto-set published_at when status changes to published
        static::updating(function ($post) {
            if ($post->isDirty('status') && $post->status === 'published' && empty($post->published_at)) {
                $post->published_at = now();
            }
        });
    }

    public function getActivitylogOptions(): LogOptions
    {
        return LogOptions::defaults()
            ->logOnly(['title', 'slug', 'status', 'published_at'])
            ->logOnlyDirty()
            ->dontLogEmptyChanges()
            ->setDescriptionForEvent(fn ($event) => "Post {$event}");
    }
}
```

## 3. Livewire Components

### 3.1 PostsList Component

**File:** `app/Livewire/Posts/PostsList.php`

Features:
- Pagination (WithPagination)
- Search by title or content
- Filter by status (All, Draft, Published, Archived)
- Filter by author (optional dropdown)
- Sorting by title, created_at, published_at
- Bulk delete (with confirmation)
- Single delete (with confirmation, prevent deleting own posts? optional)
- Toggle publish status (draft ↔ published)
- Activity logging for all changes
- Toast notifications

### 3.2 PostForm Component

**File:** `app/Livewire/Posts/PostForm.php`

Fields:
- `postId` (Locked, nullable)
- `title` (string)
- `slug` (string, optional - can auto-generate but editable)
- `excerpt` (string, nullable)
- `content` (string, textarea)
- `featured_image` (string URL or file upload? - start with URL input)
- `author_id` (select dropdown of users)
- `status` (select: draft, published, archived)
- `published_at` (datetime, nullable - only show when status = published)

Methods:
- `mount(?int $postId)`: Load existing post data
- `rules()`: Validation rules
- `save()`: Create or update post, log activity, redirect with toast
- `generateSlug()`: Manual slug generation (optional livewire action)

## 5. Routes

**File:** `routes/web.php`

Add within the authenticated middleware group:

```php
// Posts management
Route::get('/posts', \App\Livewire\Posts\PostsList::class)->name('posts.index');
Route::get('/posts/create', \App\Livewire\Posts\PostForm::class)->name('posts.create');
Route::get('/posts/{post}/edit', \App\Livewire\Posts\PostForm::class)->name('posts.edit');
```

Note: Livewire will automatically resolve the `{post}` parameter by ID.

## 7. Permissions (Optional Enhancement)

If you want granular permissions for posts, you can:

1. Run `php artisan permission:create-permission posts.viewAny` etc.
2. Add policy checks in Livewire components (like UsersList does with Auth::id checks)
3. Or keep simple: only admins/editors can manage posts via role assignment

**Recommended quick approach:** Add a middleware gate check in the route group or in component `mount()` method to ensure only users with `viewAny` permission or `admin` role can access. Can be added later.
